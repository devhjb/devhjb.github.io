## 公开与隐私边界

这个仓库是公开展示层，只放适合对外发布的内容。

后续如果把个人 MyVault 纳入 Git 管理，建议采用双仓库结构：

- 私有仓库：保存完整 MyVault、原始笔记、项目复盘、草稿和不适合公开的内容。
- 公开仓库：保存从私有知识库中筛选、脱敏、改写后的文章和作品集页面。

不要把完整 MyVault 直接推到这个公开仓库。公开内容应该经过筛选、脱敏和二次编辑。
